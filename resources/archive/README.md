# archive —— 已淘汰资源的软删除区

把不再有效、不想展示的资源 md **移动到这个文件夹**即可（不要改文件内容）：

1. 在文件管理器里把 md 从 `resources\` 根目录剪切到 `resources\archive\`
2. 双击 `deploy.bat`（或先 `build.bat` 本地预览）

构建脚本只扫描 `resources\` 根目录的 md，这个子文件夹会被自动忽略，
所以移进来 = 线上卡片消失，但底稿还留在你手里。

想恢复某条资源：把它移回 `resources\` 根目录，重新构建即可。
彻底不要了：直接删文件（git 历史里永远找得回来）。
